# RAG-помощник для поиска информации в текстах А. П. Чехова

Консольное приложение на основе технологии RAG (Retrieval-Augmented Generation), предназначенное для автоматизации поиска информации в литературных произведениях (на примере заданий ОГЭ по информатике).

## Возможности
- Поиск точной информации по запросу (например, "Какое звание у персонажа Родэ?").
- Гибридный поиск: векторный поиск по смыслу + точный поиск по тексту (JSON).
- Генерация ответов с помощью локальной нейросети (без интернета и API-ключей).
- Защита от галлюцинаций (если ответа нет в тексте, система честно сообщает об этом).

## Технологический стек
- **Язык:** Python 3.12
- **Эмбеддинги:** `intfloat/multilingual-e5-small`
- **Векторная БД:** `ChromaDB`
- **Генерация (LLM):** `qwen2.5:7b` (через Ollama)

## Структура проекта
- `data/` — тексты произведений (в формате `.txt`).
- `src/ingest.py` — нарезка текстов на чанки.
- `src/embed.py` — векторизация и запись в ChromaDB.
- `src/search.py` — тестовый скрипт для проверки поиска.
- `src/generate.py` — основной скрипт (поиск + генерация ответа).
- `docs/` — отчетная документация.
